# YAML Spec Agents

Семейный бот поддерживает добавление новых агентов через YAML-файлы в этой папке.
Каждый файл описывает одного агента.

## Формат файла

```yaml
name: agent_name            # уникальное имя агента (обязательно)
description: "описание"     # краткое описание (обязательно)
instructions: |             # системный промпт (обязательно)
  Многострочный текст
  инструкций для LLM.
model: main                 # main или lite (необязательно, по умолчанию main)
capabilities:               # список возможностей (обязательно)
  - CapabilityName
streaming: false            # (необязательно)
voice_reply: false          # отправлять ответ голосом (необязательно)
```

## Доступные возможности (capabilities)

| Имя | Что делает |
|-----|-----------|
| `JokeCapability` | Рассказывает шутки и анекдоты |
| `StoryCapability` | Генерирует сказки на ночь |
| `StickerCapability` | Отправляет стикеры |
| `WebSearchCapability` | Ищет информацию в интернете |
| `VoiceReplyCapability` | Отправляет ответ голосом (TTS) |
| `PsychologyCapability` | Консультирует по детской психологии |

## Добавление нового агента

1. Создай файл `my_agent.yaml` в этой папке
2. Заполни поля по образцу выше
3. Перезапусти бота (`make run`)

Агент автоматически загрузится при старте. Файлы, начинающиеся с `_` (например `_draft.yaml`), игнорируются.

## Теги

Агенты становятся доступны по тегам в чате. Таблица тегов настраивается в `app/agents/router.py` (секция `TAG_MAP`). По умолчанию:
- `#сказка` / `#story` → storyteller
- `#психолог` / `#psy` → psychologist
- `#шутка` / `#joke` / `#анекдот` → joker
